# AGENTS.md

Full-stack e-commerce storefront (SHOP.CO clone). Two apps: `frontend/` (Next.js 15 App Router, TS, Tailwind v4) + `backend/` (FastAPI, async SQLAlchemy 2.0, Postgres). See `docs/PROJECT_REQUIREMENTS.md` and `docs/DESIGN_SYSTEM.md`.

## Commands

Use **pnpm** (not npm/yarn) in `frontend/`.

```bash
cd frontend && pnpm install
pnpm dev          # next dev --turbopack (mock API, no backend needed)
pnpm lint         # eslint
pnpm typecheck    # tsc --noEmit
pnpm test         # vitest run (src/**/*.test.ts, node env)
pnpm build        # next build --turbopack

cd backend && pytest          # in-memory SQLite, no Postgres required
docker compose up             # full stack (postgres + api + web)
```

Single test: `pnpm test -- <path>` (vitest) / `pytest tests/test_api.py -k test_product_detail`.

CI order (`backend-test`/`frontend-test`): frontend runs `lint → typecheck → test`; backend runs `pytest`.

## Catalog data — TWO sources, keep in sync

Product/category/review seed data is **duplicated** and must match:
- `backend/app/seed.py` (Python, canonical for API)
- `frontend/src/mocks/db.ts` (TypeScript, mock API)

16 products, ids `p1..p16`, same slugs/prices/ratings in both. Adding a product means editing both.

## Mock vs real API

Frontend defaults to **MSW mock** (`NEXT_PUBLIC_API_MOCK !== "false"`). `pnpm dev` never talks to the backend. To hit the real API:

```bash
NEXT_PUBLIC_API_MOCK=false BACKEND_URL=http://localhost:8000 pnpm dev
```

`next.config.ts` rewrites `/api/:path*` → `BACKEND_URL` (default `http://localhost:8000`). `public/mockServiceWorker.js` is committed/generated by MSW — don't delete.

## Gotchas

- **Prices are integer minor units** (`18000` = `$180.00`). API returns raw ints; UI divides by 100. Test asserts `price == 18000`.
- **No Alembic** (README mentions it but none exists). Schema is `Base.metadata.create_all` via `init_db()` on startup + `seed()`. Schema changes mean editing `backend/app/models.py`; tables auto-created, no migration files.
- **Backend tests use SQLite** (`sqlite+aiosqlite://`, `StaticPool`) and override `get_session` via `app.dependency_overrides` — no DB service needed for `pytest`.
- **Design tokens only** — no raw hex or arbitrary values in `frontend/`. Use semantic utilities from `src/styles/theme.css` (e.g. `text-primary`, `bg-surface`, `text-title`, `rounded-card`). Page width via `.container-page`. Fonts: Satoshi (body) + Archivo Black (display), injected as `--font-satoshi`/`--font-archivo-black`.
- **`@/` alias** → `frontend/src/` (tsconfig + vitest both map it).

## Architecture

- `backend/app/`: `api.py` (all routes, in-memory filter/sort/paginate), `models.py`, `schemas.py`, `seed.py`, `config.py` (pydantic-settings, env `DATABASE_URL`/`CORS_ORIGINS`). App entry: `app.main:app`.
- `frontend/src/`: `app/` (pages: home, shop, product/[slug], cart, checkout), `components/` (RSC by default, `'use client'` only at interactive leaves), `lib/` (api hooks via React Query), `mocks/` (MSW handlers + data), `stores/` (Zustand cart).
- Codegen conventions for Figma→JSX live in `.opencode/skills/figma-to-nextjs-tailwind.md`.
